# VarTrotter

**Variable-weight Trotterization for coherent error suppression in quantum synthesis and control**

`VarTrotter` is a lightweight Python implementation of fixed- and variable-weight
Trotterization schemes.

The main idea is to keep the underlying pulse sequence fixed while allowing the
coefficients of the available Hamiltonians to vary from one Trotter step to the next.
These additional control degrees of freedom can be used to compensate for coherent
errors accumulated during the evolution.

For suitable control Hamiltonians, scheduled weights can improve the global
first-order Trotter error from $O(N^{-1})$ to $O(N^{-2})$, without changing the basic
pulse skeleton.

The repository contains the numerical experiments accompanying the related work on
variable-weight Trotterization.

---

## Overview

Suppose a target unitary is written as $U = e^{iH}$, and the available controls are 
generated by Hamiltonians $\mathcal H = \{H_1,\ldots,H_M\}$.

A standard fixed-weight first-order Trotterization uses

$W =\left(\prod_{j=1}^M e^{ic_jH_j}\right)^N.$

In the variable-weight setting, the coefficients are allowed to depend on the
Trotter step

$W =T^{(N)}T^{(N-1)} \cdots T^{(1)}$

with

$T^{(n)} = \prod_{j=1}^M e^{ic_j^{(n)}H_j}$

and where the schedule $c^{(1)},\ldots,c^{(N)}$ is chosen adaptively so that the drift
introduced at the current step compensates for the leading error accumulated at
previous steps.

From a quantum-control perspective, this corresponds to modifying pulse
durations/amplitudes while preserving the ordering of the available controls.

---

## Features

- Fixed-weight first-order Trotterization
- Variable-weight / scheduled Trotterization
- Real-valued coefficients (`coeffs="R"`)
- Integer coefficients (`coeffs="Z"`) for gate-synthesis-like experiments
- Direct computation of the observed operator-norm error
- Standard first-order Trotter error estimates
- Transport-identity / coherent-error estimate
- Generation of the numerical experiments used in the accompanying work
- Utilities for random elements of \(\mathfrak{su}(d)\), commutators, and pulse sets
